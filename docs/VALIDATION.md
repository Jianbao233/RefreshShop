# 0.3.2 验证范围

2026-11-06，当前 SDK 和 0.107.1 SDK 各 426 项无头、静音断言通过，配置与迁移 24 项通过。跨角色开关开启和关闭的双进程原生 ENet 测试覆盖主机单装、客机单装，包含另一角色遗物的生成、购买与未安装端接收。

本次修复已复现的药水候选为空导致整次刷新取消的路径。跨角色遗物开关默认关闭，旧 JSON 缺少该键时也保持关闭，RitsuLib 与 ModConfig 回调和跨进程恢复均覆盖。失败提示包含阶段与原因，日志输出完整异常堆栈。

玩家 dis 的具体失败原因仍待其当次日志确认。本轮发布不据候选池边界的复现推断所有玩家失败原因相同。

## 0.3.0 历史基线

日期：2026-11-04。下述功能验收基线为 0.3.0-local.1；0.3.0 仅调整版本与发布文案，不改变生产逻辑。正式包发布前重复配置、当前 SDK 和双进程 ENet 检查；脚本报告记录实际 DLL 哈希。

| 范围 | 结果 | 说明 |
| --- | --- | --- |
| 配置与迁移 | 19 项通过 | 跨进程恢复、JSON 优先、缺失键迁移、早期修改、设置回调、边界值、损坏文件、写入失败和并发保存 |
| 当前安装版原生回归 | 411 项通过 | 原生商品生成、五角色／解锁状态、80 次刷新、随机流、抓取袋、回滚、补货、黑名单空池 |
| 0.107.1 SDK 回归 | 411 项通过 | 使用旧 DLL 和当前 PCK，证明接口与测试逻辑兼容，不代表旧客户端完整运行验收 |
| 原生消息与故障注入 | 包含在上述回归 | 主机／客机角色、卡牌／药水／遗物购买、异步扣费失败、生成失败、重入保护、发送异常 |
| 原生按钮场景 | 包含在上述回归 | 原生输入动作、焦点链接、动画父节点、免费刷新、三次界面生命周期及事件释放；商店容器为夹具 |
| 两个独立无头进程 | 46 项通过 | 原生 ENet 连接，主机单装和客机单装各一轮；未安装端从未加载 RefreshShop DLL |
| 实际游戏 UI | 用户手动反馈通过 | 用户确认 UI 效果；随后按用户要求停止前台操作，所有自动测试均无头、静音 |

双进程测试经过原生握手（非强制一致 Mod 列表不同）、消息类型表、序列化、传输和接收器。每步核对刷新费用、卡牌含升级等级、药水、遗物及完整玩家随机状态；接收端还确认另一玩家未被修改。就绪／预期结果文件只用于断言，不替代游戏消息。
